## Recording plan

1. Open the live website in a clean browser window; confirm the backend data loads before recording.
2. Record at 1920×1080 or 1280×720, landscape, with zoom high enough to read chart labels.
3. Avoid hiding scientific warnings; demonstrate the **non-significant** result explicitly.
4. Capture actual interactions: monthly→annual, methodology, light/dark, JSON export and responsive sizing.
5. End on the real public URL. Keep background audio licensed or use no music; avoid copyright problems.
6. Upload as an unlisted/public-access video (not private) and test the link in an incognito window.
7. Put the final, real video URL in `PROJECT_SUBMISSION.md` and the Space Apps Project tab.
